# 🌱 SafraViva — Inteligência Viva para a sua Lavoura

Landing page conceitual desenvolvida para o **SafraViva**, uma plataforma voltada para o produtor rural que integra diagnóstico de doenças em plantas por foto com Inteligência Artificial, gestão financeira preditiva e conexão direta com consultores agrônomos.

## ✨ Funcionalidades e Destaques

- **Simulador Interativo de Diagnóstico por IA:** Card interativo na seção principal que simula o escaneamento de uma folha em SVG (estados de espera, análise com animação de varredura e resultado detalhado com identificação de sintomas).
- **Design Responsivo:** Layout adaptado para desktop, tablet e dispositivos móveis, incluindo menu hambúrguer funcional e tabelas com rolagem horizontal em telas menores.
- **Animações de Rolagem (Scroll Reveal):** Elementos surgem suavemente conforme o usuário navega pela página, utilizando a API nativa `IntersectionObserver`.
- **Navegação Dinâmica:** Barra de navegação fixa que altera seu estilo visual (efeito *blur* e fundo sólido) ao rolar a página.
- **Seções Estruturadas:** Apresentação do problema, fluxo de funcionamento em 3 etapas, explicação do diagnóstico por IA, grade com 7 módulos integrados, tabela comparativa com concorrentes e gráfico de projeção de crescimento.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e ícones em SVG inline.
- **CSS3:** Variáveis CSS (Design Tokens), Flexbox, CSS Grid, animações (`@keyframes`), responsividade com `@media` queries e tipografia via Google Fonts (*Bricolage Grotesque* e *Hanken Grotesk*).
- **JavaScript (Vanilla JS):** Manipulação do DOM, eventos de clique/rolagem e `IntersectionObserver`.
